# Obrázky k dodání

Tento web je nově plně responsivní s podporou dark mode a Tailwind CSS. Aby vypadal naprosto profesionálně, doplň prosím tyto obrázky do `src/img/`:

## Nezbytné (chybí, web je bez nich méně profesionální)

| Soubor | Rozměr | Účel |
|---|---|---|
| `og-default.png` | 1200×630 | OpenGraph náhled pro homepage při sdílení na FB / X / LinkedIn. Aktuálně se používá 40×40 ikona – sdílí se rozplizle. |
| `favicon.svg` | vektor | Moderní favicon (SVG zvládá tmavý režim přes `<style>` v SVG). |
| `favicon-32.png` | 32×32 | Fallback pro starší prohlížeče. |
| `favicon-192.png` | 192×192 | Android instalace. |
| `apple-touch-icon.png` | 180×180 | iOS Safari domovská obrazovka. |

## Velmi doporučené (zvedne brand)

| Soubor | Rozměr | Účel |
|---|---|---|
| `hero-illustration.svg` nebo `.webp` | min. 800×800 | Hlavní vizuál na homepage. Ideálně line-art s teal akcenty (postava + měřící prvky). Aktuálně tam je SVG mock-up gauge. |
| `og-bmi-kalkulacka.png` | 1200×630 | Zatím se sdílí default; vlastní pomůže CTR. |
